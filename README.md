## ✨ 能帮你什么

### 🗺️ 他们去过哪、怎么去的？
追星时总想知道他们最近去了哪里、走了什么路线。地图上把所有行程路线和事件地点都标了出来——弧形虚线是飞行/乘车路径，圆点是事件地点。点一下就能看到日期、详情，看不全还能切换底图。

### 📍 应援打卡点在哪、怎么去？
全国 **38 城**的应援打卡点列表，不用再到处翻微博找位置。选好分类/城市/品牌，点「导航」直接跳转到高德 / 苹果 / 谷歌 / 腾讯地图带路：

| 分类 | 色标 | 说明 |
|------|:----:|------|
| 💙 **爱情圣地** | `#094FA7` 深蓝 | 两位相识/同框的重要地点，不过期 |
| 🧡 **52 圣地** | `#FF5722` 深橙 | 52 取景地及相关主题痛店 |
| 💜 **活动商务** | `#9C27B0` 紫 | 公开活动、商务合作场地 |
| 🩷 **应援打卡** | `#FF69B4` 粉红 | 大屏 / 痛楼 / 巴士站牌 / 花车等 |
| 💚 **主题商店** | `#4CAF50` 绿 | 品牌主题店、快闪店 |

选太多了？一键全选/取消，还可以只看香港。

### 📱 想按地点看、按时间看、还是看统计？
底部导航栏五个视图自由切换：

1. **打卡** — 默认首页，打卡点列表+多维筛选排序
2. **行程** — 全部路线与事件时间线
3. **日历** — 按日期查看，附中国农历
4. **统计** — 旭日图/月度柱状图/城市排行 TOP 10
5. **留言** — 每条行程/打卡点都有独立评论区

不想看全部人？筛一下：**全部 / 云旗 / 郝熠然 / 双人**。

### ⏱️ 只看某段时间的行程？
双滑块一拖，地图、列表、日历、图表同步只显示该时间范围的内容。点「重置」一键恢复。

### 🔗 在日历看到行程，还得手动去地图找？
不用。日历点日期 → 地图飞到对应位置；地图点标记 → 日历跳到对应日期；列表点卡片 → 地图定位高亮。双向联动，随手点就行。

### 👁️ 想只看一个人的行程？
分别控制云旗 / 郝熠然 / 双人的显示和隐藏。打卡标记也能单个开关，点亮的地图标记卡片会高亮边框。

### 💬 想跟同担交流？
每条行程和打卡点下面都有评论区，可以留言补充信息、分享打卡照片。

## 🚀 怎么用

1. 打开 [yunyi-map.pages.dev/](https://yunyi-map.pages.dev/)（国内推荐）或 [GitHub Pages 镜像](https://penapinner.github.io/yunyi-map/)
2. **打卡导航**：进入首页就是打卡视图 → 选择分类/城市/品牌筛选 → 点击打卡卡片上的「导航」按钮 → 选择高德/苹果/谷歌/腾讯地图跳转导航
3. **行程浏览**：底部切换到**行程视图**，查看所有路线与事件时间线；切换到**日历视图**按日期浏览行程
4. **可视化统计**：底部切换到**统计视图**，查看旭日图/月度柱状图/城市排行，直观了解他们的出行足迹
