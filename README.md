## ✨ 功能一览

### 🗺️ 交互式行程地图
- 云旗、郝熠然的**全部行程路线**以**弧形虚线**在地图上动态展示
- 飞行/乘车路径清晰可辨，起点终点彩色圆点标记
- 点击任意标记查看详情：日期、地点、外部链接
- 基于 Leaflet.js + 腾讯瓦片地图，流畅缩放拖拽

### 📍 全国应援打卡导航
覆盖 **13+ 城市**的应援打卡点集中展示，**一键导航**到高德 / 苹果 / 腾讯 / 百度地图：

| 分类 | 说明 |
|------|------|
| 💛 **爱情圣地** | 两位相识/同框的重要地点 |
| 💚 **52 圣地** | 郝熠然 5 月 2 日生日应援相关 |
| 💙 **活动商务** | 公开活动、商务合作场地 |
| ❤️ **应援打卡** | 粉丝应援点（大屏 / 痛楼 / 巴士站牌 / 花车等） |
| 🧡 **主题商店** | 品牌主题店、快闪店 |

每个打卡点附精准定位、地址信息，跟着地图就能找到同担打卡点。

### 📅 三种视图模式
- **打卡视图** — 默认首页，打卡点列表 + 分类 / 城市筛选
- **日历视图** — 日历模式查看行程，显示**中国农历**和传统节日
- **列表视图** — 完整行程路线与事件时间线

三种视图均支持按人物筛选：**全部 / 云旗 / 郝熠然 / 双人**。

### 📊 数据统计面板
- 🌅 **旭日图**：行程构成一目了然（单人 vs 双人、路线 vs 事件）
- 📈 **月度堆叠柱状图**：每月出行频次分布
- 🏆 **城市排行**：到访最多城市 TOP 10

### ⏱️ 时间拉杆
- 双滑块时间范围筛选，**地图 / 列表 / 日历 / 图表**全部联动更新
- 一键「重置」恢复全部时间范围

### 🔗 联动交互
- **日历 → 地图**：点击日期，地图自动飞到对应行程位置
- **地图 → 日历**：点击弹窗的「日历」按钮，自动跳转选中日期
- **列表 → 地图**：点击行程卡片，地图定位并高亮

### 💬 评论区
- 基于 **giscus**（GitHub Discussions）的留言板
- 每条行程 / 事件 / 打卡点都有独立评论区
- 同担可以留言交流、补充信息、分享打卡照片

## 🚀 怎么用

1. 打开 [yunyi-map.pages.dev/](https://yunyi-map.pages.dev/)（国内推荐）或 [GitHub Pages 镜像](https://penapinner.github.io/yunyi-map/)
2. 左侧边栏切换视图：**打卡 / 日历 / 列表**
3. 点击地图上的标记查看详情，点击打卡点的「导航」按钮跳转地图 App
4. 下方时间拉杆可筛选特定时间段，统计面板查看数据概览
